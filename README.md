# ☕ Starbucks Coffee Ukraine — Landing & Table Booking

Сучасний, адаптивний веб-сайт кав'ярні **Starbucks** з інтерактивним меню, кошиком замовлень, валідацією контактних даних та формою бронювання столиків.

---

## 🚀 Основні можливості

- **Головний екран (Hero)**:
  - Елегантна анімація з презентацією сезонного напою *Pumpkin Spice Crème*.
  - Фірмові бейджі знижок (`-45%`) та розетка в стилі Starbucks.
  - Адаптивність під смартфони, планшети та комп'ютери.
- **Інтерактивне меню напоїв**:
  - Фільтрація за категоріями: Еспресо, Авторські лате, Холодна кава, Чайні композиції, Десерти.
  - Вибір об'єму (Short, Tall, Grande, Venti), типу молока (вівсяне, мигдальне, кокосове, безлактозне) та фірмових сиропів.
  - Калькуляція цін у реальному часі в гривнях (₴) та доларах ($).
- **Кошик та швидке замовлення**:
  - Додавання та видалення позицій, автоматичний перерахунок суми.
  - Оформлення замовлення самовивозом біля стійки видачі.
- **Форма бронювання столика з розумною валідацією**:
  - **Поле імені**: дозволяє введення тільки літер (українські та латинські), блокує цифри та спецсимволи на льоту.
  - **Поле телефону**: суворо починається з `+380` та автоматично форматує номер у вигляді `+380 (XX) XXX-XX-XX`, відсікаючи випадкові літери чи неповні номери.
- **Інтерактивна модалка «Процес приготування»**:
  - Покрокова візуалізація стандарту обсмажування, екстракції та збивання молока.
- **Футер з атрибуцією**:
  - Посилання на соцмережі, контакти, кнопка прокрутки вгору та посилання на розробника [monvorgestudio.com](https://monvorgestudio.com).

## 🛠 Технологічний стек

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Збірка**: [Vite](https://vitejs.dev/)
- **Стилізація**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Іконки**: [Lucide React](https://lucide.dev/)
- **Анімації**: Motion (Framer Motion)

## 📦 Встановлення та запуск

### 1. Клонування репозиторію
```bash
git clone https://github.com/ВАШЕ_ІМЯ/starbucks-coffee-landing.git
cd starbucks-coffee-landing
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск у режимі розробки
```bash
npm run dev
```
Сайт відкриється за адресою `http://localhost:3000`.

### 4. Збірка для продакшену
```bash
npm run build
```
Готові оптимізовані файли будуть створені в директорії `/dist`.

### 5. Попередній перегляд білду
```bash
npm run preview
```

### 6. Перевірка типів (TypeScript)
```bash
npm run lint
```

## 📁 Структура проєкту

```text
├── src/
│   ├── assets/              # Зображення та статичні файли
│   ├── components/          # Компоненти інтерфейсу
│   │   ├── Navbar.tsx           # Верхнє навігаційне меню та перемикач мобільний/десктоп
│   │   ├── HeroSection.tsx      # Головний екран із презентацією напою
│   │   ├── ProductsSection.tsx  # Каталог продукції з модалками вибору
│   │   ├── WeMakeSection.tsx    # Секція стандартів обсмажування та приготування
│   │   ├── EventsSection.tsx    # Секція майстер-класів та дегустацій
│   │   ├── ContactsSection.tsx  # Контакти та форма бронювання столика
│   │   ├── Footer.tsx           # Футер з копірайтом і посиланням на студію
│   │   ├── Modals.tsx           # Модалки кошика, деталей та процесу приготування
│   │   └── ScallopedBadge.tsx   # Фірмова графічна розетка
│   ├── utils/
│   │   └── validation.ts        # Валідація та маска телефону +380 / імені
│   ├── App.tsx              # Головний контейнер сайту
│   ├── main.tsx             # Точка монтування React
│   └── index.css            # Глобальні стилі Tailwind
├── index.html               # HTML-шаблон з OpenGraph та шрифтами
├── package.json             # Залежності та скрипти
├── tsconfig.json            # Налаштування TypeScript
└── vite.config.ts           # Налаштування Vite
```
